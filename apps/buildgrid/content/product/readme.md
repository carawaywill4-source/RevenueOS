# BuildGrid — Construction Coordination Toolkit

Thank you for purchasing **BuildGrid**.

This toolkit is designed for project managers, superintendents, and general contractors coordinating commercial and residential builds.

---

- `01-BuildGrid-RFI-Log-Template.xlsx` (Excel Workbook + Formulas)
- `01-RFI-Log-Template.csv` (Raw CSV Data format)
- `02-BuildGrid-Three-Week-Lookahead-Schedule.xlsx` (Excel Schedule)
- `02-Three-Week-Lookahead-Schedule.csv` (Raw CSV Data)
- `03-BuildGrid-Room-by-Room-Punch-List.xlsx` (Excel Defect Tracker)
- `03-Room-by-Room-Punch-List.csv` (Raw CSV Data)
- `04-BuildGrid-CSI-Submittal-Log-Tracker.xlsx` (Excel Submittal Log)
- `04-Submittal-Log-Tracker.csv` (Raw CSV Data)
- `05-BuildGrid-Project-Manager-Quick-Start-Guide.md` (Instructions & Field Cadence)
